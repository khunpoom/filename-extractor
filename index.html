ลากไฟล์มา ได้รายชื่อทันที

ดึงชื่อไฟล์จากหลายไฟล์หรือทั้งโฟลเดอร์ ส่งออกเป็นข้อความ CSV หรือ JSON — ไฟล์ไม่ออกจากเครื่องคุณ

วางไฟล์หรือโฟลเดอร์ที่นี่

ลากมาวาง หรือเลือกจากเครื่อง

# ชื่อไฟล์ นามสกุล ขนาด พาธ 

        


        

          
01
เลือกหลายไฟล์ หรือทั้งโฟลเดอร์ (รวมโฟลเดอร์ย่อย)

          
02
ถ้าเป็นไฟล์ ZIP สามารถอ่านรายชื่อข้างในได้โดยไม่ต้องแตกไฟล์

          
03
เลือกว่ารายชื่อจะเป็นชื่ออย่างเดียว นามสกุล หรือพาธ แล้วคัดลอกหรือดาวน์โหลด

        


        

          

            
โปรแกรม Windows

            
Namely.exe

            

              ดาวน์โหลด .exe แล้วดับเบิลคลิกบนเครื่อง Windows — เลือกโฟลเดอร์ แล้วได้ไฟล์รายชื่อทันที หรือลากโฟลเดอร์มาวางบนไอคอนโปรแกรม
